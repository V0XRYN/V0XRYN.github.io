# V0XRYN

**Explore. Build. Evolve.**

A digital journey through technology, Linux, AI, cybersecurity and creation.

## About

V0XRYN is a personal digital brand covering:

- Technology & Linux
- AI & AI agents
- Cybersecurity
- Software development
- Projects & creation
- Experiments, tutorials and technical discoveries

Cybersecurity remains a core domain but coexists naturally with Linux, AI, technology, software and future projects.

## Structure

```
/index.html              Home / Hero, Domains, About, Skills, Projects, Blog, Connect
/404.html                Custom branded 404 page
/blog/                   Individual article pages
/assets/css/style.css    Design system and component styles
/assets/css/article.css  Article page styles
/assets/js/main.js       Navigation, scroll spy, mobile menu, reveal animations
/assets/js/projects.js   Live GitHub project fetching with filters and fallback
/assets/js/blog.js       Blog content and rendering
/assets/js/search.js     Client-side search across projects and blog
/assets/img/             Brand assets (logo, favicons, OG image, manifest)
```

## Deployment

This site is deployed via GitHub Pages from the `main` branch. `.nojekyll` disables Jekyll processing for static HTML/CSS/JS.
